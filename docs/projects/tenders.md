# Проект: тендеры (заготовка)

Общие правила — [00_ПРОЧИТАЙ_СНАЧАЛА](https://kos-company.github.io/kos-rules/read-first.html). Заполнить при запуске проекта.

## Особые правила (черновик)
- Тексты технических заданий и заявок — только по документам изделия (документ относится к модели, только если артикул внутри документа); соответствие КТРУ/ТЗ проверять построчно, расхождения — вопрос человеку.
- Сроки, суммы, номера закупок — только из карточки закупки (источник + дата). Не выдумывать.
- Ничего не подавать и не подписывать — только черновики для человека.

- Медицинские формулировки здесь НЕ ограничены правилами маркетплейсов: в тендерах термины КТРУ/ТЗ используются как есть. Свои правила — решает юрист проекта.
