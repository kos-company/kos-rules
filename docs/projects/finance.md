# Проект: финансовые отчёты по маркетплейсам

Общие правила — [00_ПРОЧИТАЙ_СНАЧАЛА](https://kos-company.github.io/kos-rules/read-first.html).

## Цель
Ежедневные и еженедельные финансовые отчёты WB, Ozon, ЯМ без ручных выгрузок.

## Как устроено
- Программа «финансовый комплект» на ПК финансиста, свои ключи только на чтение в хранилище Windows. Нейронка ключей не видит и в API не ходит.
- Выход: папка exports_finance/<дата> — CSV по отчётам + manifest.json.
- Нейронка работает только с этими файлами и промптом ПРОМПТ_ДЛЯ_ИИ.md из комплекта.

## Правила
- Начинать с manifest: период, статус, число строк. gap = ошибка, не ноль.
- Не путать «к перечислению» с фактической выплатой; расшифровку не прибавлять к итогу, который её включает.
- Месячная реализация Ozon не складывается с недельными транзакциями.
- Реклама — пробел, если нет отдельного файла рекламы.
- Метод WB: только новый финансовый API; старый reportDetailByPeriod отключён — не предлагать.
- Статус: пилот до сверки с кабинетом за закрытую неделю.
