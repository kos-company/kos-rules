# Как запустить Проводника КОС

## руководитель настраивает общий проект

1. В ChatGPT выберите New project и назовите проект «Проводник КОС».
2. Откройте меню проекта → Project settings. Вставьте содержимое файла [ИНСТРУКЦИЯ_ПРОВОДНИКА](https://kos-company.github.io/kos-rules/guide/instructions.html) в инструкции проекта.
3. Добавьте в инструкции проекта ссылку на [оглавление](https://kos-company.github.io/kos-rules/) и попросите Проводника читать указанные страницы перед ответом. В новом чате проверьте приветствие и предупреждение о видимости.
4. Откройте Share → Only those invited. Введите рабочую почту каждого сотрудника, выберите Chat access («только чат», без редактирования) и нажмите Invite. Сотрудники получат приглашение по почте.
5. Проверьте доступ с одним приглашённым сотрудником. Отправьте сотрудникам ссылку на [оглавление](https://kos-company.github.io/kos-rules/).

Общими проектами можно делиться на всех тарифах ChatGPT с учётом настроек рабочего пространства. На Plus — до 25 файлов и 10 участников совместной работы. Участники видят чаты проекта, их авторов и общие файлы. Общий проект использует память только внутри проекта и не обращается к личной памяти участников. Work в проекте с такой памятью недоступен. [Справка OpenAI о проектах](https://help.openai.com/en/articles/10169521)

## Сотрудник начинает с приглашения

Примите приглашение и напишите «Привет» в новом чате проекта. Здесь задавайте вопросы по настройке. Рабочие файлы, данные клиентов и цифры держите в отдельном рабочем проекте, который Проводник поможет настроить по 04.

GPT сворачиваются, не используем.

## Обновления

Правьте источник в репозитории правил, проверяйте страницы после публикации.
