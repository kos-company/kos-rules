# 03 · Данные: откуда брать и как проверять

## Источники
Конкретные источники каждого проекта — в его ИНСТРУКЦИИ. Общий принцип: данные берутся из общей папки «Данные», которую наполняют программы; нейронки и сотрудники не ходят за ними сами в API и кабинеты, если проект прямо не разрешает иное.

## Паспорт выгрузки
Каждая выгрузка программы имеет паспорт (manifest.json или лист «Паспорт»): площадка, период, время, метод, число строк, статус (ok / no_data / gap — ошибка).
Нейронка начинает с паспорта. «gap» — данных нет из-за ошибки, это не ноль.

## Проверки, которые не зависят от нейронки
1. Контрольная цифра: человек сверяет 1–2 числа из ответа нейронки с паспортом или исходным файлом. Не совпало — ответ не использовать.
2. Раз в неделю одна цифра из отчёта сверяется с кабинетом площадки.
3. Итоги и сводные таблицы по возможности считает программа; нейронка объясняет.
4. Ничего не уходит на площадки и клиентам без проверки человеком.
