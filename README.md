# Правила КОС

Начните с [оглавления GitHub Pages](https://kos-company.github.io/kos-rules/). Здесь правила и промпты. Рабочие данные находятся в закрытой папке проекта.

В публичный репозиторий входят только правила, инструкции, памятки и промпты без внутренних данных. Пароли, токены, ключи, ФИО, почты, телефоны, сведения о продажах, ценах, запасах, обороте, инцидентах и блокировках карточек, ID закрытых файлов и личные сведения остаются за его пределами. Сомнительные материалы направляй в закрытый репозиторий. Проверяй изменения перед каждым пушем.

Перед каждым пушем выполните `pwsh -NoProfile -File ./check-public.ps1` и проверьте изменения вручную.
